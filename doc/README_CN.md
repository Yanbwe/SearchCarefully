# 仔细搜索 SearchCarefully

SearchCarefully是一个Minecraft模组，为游戏添加了类似塔科夫的战术搜索功能，允许玩家逐步搜索物品以揭示其内容。

## 功能特性

- **物品搜索系统**：对容器中的物品进行逐步搜索，大幅增加玩家的搜索体验。
- **赏心悦目**：纹理和音效全部都可以自定义。
- **高度可配置**：支持为不同稀有度的物品配置不同的搜索时间
- **好兼容**：支持所有结构战利品箱。

## 前置模组
